Cara Mendapatkan client_secrets.json (100% Gratis & Resmi Google):
  1. Buka Google Cloud Console dan buat proyek baru.
  2. Aktifkan YouTube Data API v3 di menu APIs & Services > Library.
  3. Di menu Credentials, klik Create Credentials > OAuth client ID (Pilih tipe: Desktop App).
  4. Unduh file JSON yang dihasilkan, ubah namanya menjadi client_secrets.json, lalu letakkan di folder proyek ini (E:\PROJECTS\kajian_clipper).
  5. Klik tombol "Hubungkan Akun YouTube Sekarang" di atas. Selesai!
